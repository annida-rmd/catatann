Infix To Postfix

Diberikan sebuah string s yang mewakili ekspresi infix ("operand1 operator operand2"), Ubahlah ke notasi postfixnya ("operand1 operand2 operator").

Urutan prioritas

  • (^) memiliki prioritas tertinggi dan dievaluasi dari kanan ke kiri
  • (* dan /) berada di urutan berikutnya dengan asosiatif dari kiri ke kanan
  • (+ dan -) memiliki prioritas terendah dengan asosiatif dari kiri ke kanan

Contoh Code

Input: s = "a*(b+c)/d"
Output: abc+*d/
Penjelasan: Ekspresi tersebut adalah a * (b + c) / d.
Pertama, di dalam tanda kurung, b + c menjadi bc+. Sekarang ekspresi tersebut terlihat seperti a * (bc+) / d.
Selanjutnya, kalikan a dengan (bc+), sehingga menjadi abc+* . Terakhir, bagi hasil ini dengan d, sehingga menjadi abc+*d/.
Input: s = "a+b*c+d"
Output: abc*+d+
Penjelasan: Ekspresi a + b * c + d dikonversi dengan terlebih dahulu melakukan b * c → bc*, kemudian menambahkan a → abc*+, dan akhirnya menambahkan d → abc*+d+.
