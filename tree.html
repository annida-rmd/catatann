Antrian

Deque adalah singkatan dari Double-Ended Queue (Antrean Dua Ujung). Ini adalah jenis struktur data khusus yang memungkinkan Anda untuk menambahkan dan menghapus elemen dari kedua ujungnya secara efisien. Hal ini membuatnya berguna dalam aplikasi seperti penjadwalan tugas, masalah jendela geser, dan pemrosesan data waktu nyata.

Operasi pada antrian

  • queue (), inisialisasi struktur data queue kosong
  • enqueue (data), penambahan data baru pada queue
  • dequeue (), penghapusan data
  • isEmpty(), pengecekan apakah queue dalam keadaan kosong
  • size (), informasi jumlah data yang terdapat pada queue

Contoh Code

q = []
q.append('a')
q.append('b')
q.append('c')
print("Initial queue:", q)
print("Elements dequeued from queue:")
print(q.pop(0))
print(q.pop(0))
print(q.pop(0))
print("Queue after removing elements:", q)
