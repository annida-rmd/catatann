Double Antrian

Deque adalah singkatan dari Double-Ended Queue (Antrean Dua Ujung). Ini adalah jenis struktur data khusus yang memungkinkan Anda untuk menambahkan dan menghapus elemen dari kedua ujungnya secara efisien. Hal ini membuatnya berguna dalam aplikasi seperti penjadwalan tugas, masalah jendela geser, dan pemrosesan data waktu nyata.

Operasi pada Deque

  • Deque() : membuat deque kosong.
  • addFront(item) : menambah item di depan deque.
  • addRear(item) : menambah item di belakang deque.
  • removeFront() : menghapus dan mengembalikan item depan.
  • removeRear() : menghapus dan mengembalikan item belakang.
  • isEmpty() : mengecek apakah deque kosong (true/false).
  • size() : mengembalikan jumlah item dalam deque.

Contoh Code

from collections import deque
# membuat deque kosong
data = deque()
# menambah data
data.append("A") # tambah belakang
data.appendleft("B") # tambah depan
print(data)
# menghapus data
data.pop() # hapus belakang
data.popleft() # hapus depan
print(data)
